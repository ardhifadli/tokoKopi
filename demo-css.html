Demonstrasi & Pembelajaran Metode CSS

Halaman edukatif ini memperlihatkan tiga cara penerapan CSS dalam perancangan web, lengkap dengan analisis urutan prioritas dan spesifisitas Cascade.

1. Inline CSS (Gaya Baris)

Ini adalah teks yang diwarnai langsung menggunakan atribut style="..." (Inline CSS).

Cara Kerja: Deklarasi gaya ditulis langsung pada atribut style di dalam tag elemen HTML bersangkutan.

Kelebihan: Berguna untuk perbaikan cepat satu elemen tertentu atau pengujian darurat.
Kekurangan: Sulit dirawat, memperbesar ukuran berkas HTML, dan melanggar prinsip pemisahan struktur dan tampilan (Separation of Concerns).

2. Internal CSS (Gaya Tersemat)

Ini adalah blok teks yang dihias melalui tag <style> di dalam bagian <head> halaman ini.

Cara Kerja: Seluruh aturan CSS ditempatkan di dalam tag <style> pada bagian <head> dokumen HTML yang sama.

Kelebihan: Menampung aturan khusus untuk satu halaman tertentu tanpa mempengaruhi halaman web lain.
Kekurangan: Tidak dapat digunakan bersama antarhalaman sehingga terjadi duplikasi kode saat situs memiliki banyak berkas.

3. External CSS (Gaya Eksternal)

Seluruh tampilan visual situs Kopi Senja (tipografi, tombol, kartu produk, dan navigasi) dikendalikan melalui berkas eksternal style.css.

Cara Kerja: Aturan CSS disimpan pada berkas terpisah berekstensi .css dan dihubungkan ke berkas HTML menggunakan tag <link rel="stylesheet" href="style.css">.

Kelebihan (Standar Industri): Sangat efisien, menerapkan prinsip DRY (Don't Repeat Yourself), mendukung caching peramban web sehingga muat lebih cepat, dan mempermudah pemeliharaan jangka panjang.

Urutan Prioritas Gaya (CSS Cascade Hierarchy)

Jika suatu elemen dikenai aturan penataan dari berbagai metode secara bersamaan, peramban (browser) akan menentukan tampilan akhir berdasarkan hierarki kekuatan berikut:

Tingkat Prioritas Metode Styling Kekuatan Spesifisitas Contoh Sintaks
Prioritas 1 (Tertinggi) Inline CSS Mengalahkan internal dan external <p style="color: red;">
Prioritas 2 Internal CSS Berlaku pada satu dokumen HTML <style> p { color: blue; } </style>
Prioritas 3 External CSS Standar modular terpadu <link rel="stylesheet" href="style.css">
Prioritas 4 (Terendah) Browser Default Gaya bawaan User-Agent Default serif/sans-serif peramban

*Catatan Tambahan: Deklarasi !important dapat membalikkan hierarki ini, namun penggunaan terbaik adalah merancang selektor spesifik (ID > Class > Tag) tanpa bergantung pada !important.
